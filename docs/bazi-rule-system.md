# 八字规则体系与第一批实现

本项目以《子平真诠》的月令与格局方法为主要研究依据，《滴天髓》作概念补充。不同文本中的“用神”、现代扶抑喜用、调候取用不能不加区分地混成一套结论；每种方法需要独立的条件、来源和输出说明。

## 已实现的分析层

`structural_analysis` 由程序生成，包含月令季节、逐柱藏根观察、月支藏干透出、格局研究候选、特殊月令路径和规则来源。它不是语言模型临时编出的分析。命盘既可由历法库排出，也可由用户提供；后一种来源的排盘验证限制保留。

### 月令季节

按节气月支归类：寅卯为春、巳午为夏、申酉为秋、亥子为冬；辰未戌丑单列季末月。春木、夏火、秋金、冬水仅作传统季节关联标签，并计算其与日主五行的生克关系。没有把这个标签直接叫作“得令”，也没有为季末月统一判土旺。

季节标签是项目显式约定，不是对古籍短句的逐字算法。人元司令分日、库气轻重、寒暖燥湿和边界条件尚未计算；不能从“春木”直接得出“甲乙日主身强”。

### 逐柱通根观察

对每个天干检查四支藏干，记录位置和匹配类型：

- `same_stem`：藏干中出现完全相同的天干。
- `same_element`：藏干中出现同五行的其他天干。

两种类型都只代表实际出现，不判根力。同五行藏干、同干藏根、有效强根是不同层次；根气是否受合冲刑害影响、是否可用，以及其权重尚未建立规则。四支未见同五行藏干，也不能直接推断全盘身弱。

《子平真诠》“论十干得时不旺失时不弱”所列两段文字已在世界图书馆工作扫描本的 PDF 第 22 个扫描页、书内第 13 页看图核对。引用是分析方法的依据，不证明当前程序已实现整章根气强弱判定。原字保留、句读经现代整理。

### 月支藏干透出

月支的每个藏干，与年、月、时干逐字比较，记录相同天干的透出位置。日干是分析参照，不重复算成额外透出；同五行而字不同也不算该藏干本身透出。

例如月支子藏癸，年、月、时干都不是癸时，记录“癸未见非日干透出”，不能说全盘没有财星。藏干列表顺序不作为权重、优先级或司令分日。

### 格局研究候选

按月支藏干相对日主的十神，产生正官、七杀、正财、偏财、正印、偏印、食神或伤官的研究候选；标明具体藏干、是否透出和证据位置。所有条目为 `candidate_only`，不排名，也不宣称当前已经成格。

月支含比肩或劫财时进入特殊路径提示：按日主与月支的明确映射区分建禄、阴干月劫、五阳干阳刃；扫描本的“惟六陽”异文保留并注明待校勘。特殊路径只安排查财官煞食等配合，不直接定格。辰戌丑未进入杂气路径，记录月支藏干透出和完整三合支字组合；“支字齐备”不等于合化。

候选枚举是项目用于组织证据的保守步骤，不能等同于古籍已作出的格局结论。成败救应另有 [财格方法清单](bazi-wealth-checklist.md)，尚未提供最终格局判断。

## 干支关系与关联核查

新增 `interactions`：显干五合、支六合／六冲／六害／六破、相刑配对、自刑重复支、完整三刑支字组。配对保留实际柱位与字符；相刑按有向表列出，子卯互刑分别记录两个方向，两字不称完整三刑；自刑需要不同柱同支重复。相邻只是位置事实，不作为效力系数。

关系表见 `bazi_interactions.json`，属于项目显式采用的传统配对约定，尚未逐条与指定扫描底本校勘；不把数据表当作已核对古籍引文。当前不覆盖暗合、半合、拱合、三会、藏干之间的合或天干冲。

`root_reviews` 将参与关系的支位关联到既有藏根，保留原观察；`candidate_reviews` 列出涉及月支或候选透干的关系；`overlapping_relations` 列出同一柱参与多项关系的位置。它们都是核查清单：未判断合化、冲去、刑伤、根力受损或格局成败，不因为一个冲而删除根，不采用“贪合忘冲”“冲开财库”等未核实推断。

## 当前输出与规则追踪

```bash
fortune-bazi --pillars '己卯 丙子 戊午 戊午' --structure
fortune-bazi --birth 2000-01-01T12:00:00+08:00 --structure --json
```

网页八字结果及统一对话的依据区可展开“规则分析”。每项规则有 `source_ids`，对应原文和双重页码；`bazi_structure_rules.json` 保存定义、月支分类、候选标签和未核实条件。参考库哈希包含这份规则数据；续跑也核对实际结构输出，不混用旧规则结果。

模型收到已计算的关系和候选，须依据它们解释；仍不能把根气出现改写为根强，把透出改写为成格，或把季节标签改写为最终旺衰。无大运、喜用神等资料时，也不能推导人生吉凶和具体事件。

## 验证与限制

测试穷举十个日主与六十个月柱，核对候选来自实际月支藏干且未变成最终结论；检查同干与同五行区分、非日干透出、季末月、特殊月令映射、杂气三合证据、无根不判弱、日主一致性和来源页码。排盘和十神沿用选定库版本，结构规则也保留项目定义；这不是对命理现实预测效力的验证。

三条真实模型请求与人工复核见 [本批评估记录](../evals/results/bazi-structure-review-2026-10-04.md)，包括机械识别“癸未”的误报说明。
