# 档案确认、请求处理与问题导向解读

## 档案确认

统一对话新增已保存档案下拉框，先展示实际出生资料、经纬度与风格，再勾选确认使用。未确认时，保存档案不会提供给路由模型，也不能用它跳过资料补问。确认标识由后端针对档案快照生成；资料变化后旧标识失效，用户需重新预览确认。

确认后可复用八字出生时间/四柱、传统起运参数、星盘时间与经纬度和风格；用户明确要求的方法和新资料优先。未指定方法时才可使用确认档案的方法偏好。换档案或撤回确认会开始新的资料上下文，防止旧命盘混入；对话切换会清理之前的会话上下文。命令行发现已保存档案时，也需要明确输入yes才复用。

## 进度、取消与重试

模型请求在本机后台处理，页面轮询实际阶段：核对资料、识别需求与选择工具、核对牌面、准备结果、生成解读。显示经过时间，不显示无法保证的完成百分比。

后台请求使用不可预测编号，最多4个尚未结束的请求、保留64个可查记录与1小时有效期；容量到达时淘汰最早完成记录，不产生无限线程。所有请求仍受本机Host和页面token校验，状态与结果不写入额外磁盘日志。

取消为合作式取消：禁止后续模型调用和采用迟到回答，不增加成功对话消息；已经发到中转站的HTTP请求不保证能撤回，可能继续处理或计费。当前请求未结束时不能重试，避免并行重复计费。取消不等于关闭服务端原始任务；若取消前日报或工具历史已成功保存，取消不撤销该记录，需另行删除。

已生成的牌面、命盘或卦象会保留在本机会话/请求预览。重试由后端复用原请求：对话沿用session与artifact，手动周易保留爻值及原投掷记录，手动塔罗保留原牌面/正逆位，不重新抽取。提供方故障使用通用错误，不把响应正文或凭据显示在网页。成功请求不会被“重试”重复执行。

本模块不是跨进程的付费请求锁，网页刷新/服务重启后后台请求编号可能失效；用户须核对已保留的档案、每日缓存或实际结果。

## 解读组织

各解释工具共享问题重点提示：先直接回应问题，再解释1–3条直接相关依据，最后给两条有完成标准的行动。学习关注练习、资料与反馈；工作关注职责、依赖与交付；关系关注表达、倾听及边界；资源选择关注成本、条件与替代方案。它不从占卜结果推定用户经历，也不读取他人内心或提供确定收益指令。

必要的不确定性仍保留，引用和方法说明合并成短段，避免每段重复免责声明。八字/紫微原文和工程模型限制不因简洁措辞省略，模型回答也不因为主题分类而自动保证质量。

## 评估

回归测试覆盖未确认不发送资料、确认后的日期/四柱/风格复用、档案改动重新确认、资料上下文隔离、取消后无后续调用/迟到结果、保留原牌卦、请求容量和错误信息隐藏。浏览器使用明确提供方测试替身验证预览确认、进度、按钮状态、取消和原任务重试。

`evals/agent_experience_cases.json`为五组真实模型的小样本案例，运行：

```bash
PYTHONPATH=src python scripts/evaluate_agent_experience.py
```

需要API配置与 `.[all]`、Node运行时，会实际产生中转站请求。它衡量指定样例的方法选择、补问状态、确认档案复用及追问稳定性；不是通用准确率或预测效力评估。参考 [本批评估记录](../evals/results/agent-experience-review-2026-10-06.md)。
