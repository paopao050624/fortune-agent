# 八字综合报告与每日运势

当前版本完成本地使用流程：八字综合报告、起运与十年大运、参考流年、固定每日塔罗、八字当日关系、日报保存、历史回顾、导出与删除。新增项目判断模型，给出旺衰估计、格局条件与喜用候选。**这些是工程近似，并非各派统一的经典最终判断。**经典效力缺条件时仍保留 `unresolved`；项目判断在 `rule_judgment` 中，模型可说明它的估计结果但不能冒充经典定论。

## 八字报告

网页八字页展示完整报告；准确出生时间仍为中国标准时间，日柱午夜换日、未校正真太阳时。直接四柱只核验单柱合法性。出生时间与传统顺逆运参数都具备时，大运才计算。

```bash
fortune-bazi --birth 2000-01-01T12:00:00+08:00 --gender female --complete --date 2026-10-05 --json
fortune-bazi --pillars '己卯 丙子 戊午 戊午' --complete
```

`complete_analysis` 分四层：

- 旺衰证据：季节关联、同干／同五行藏根、可见生助及泄耗制关系，逐项列出位置。证据原样保留，项目模型另按公开权重计算旺衰估计，数值不冒充古籍标准。
- 格局：保留月支候选、特殊路径、筛选证据与合冲关联；八类候选分别列出配合、待审关系观察与具体核查问题；这些问题清单是项目整理，具体条件未逐条扫描校勘。成格与破格条件不足时保持未确定。财格三条原文路径沿用既有学习清单。
- 取用：格局、扶抑、调候分别列出方法与条件；扶抑按“若身强”“若身弱”“若特殊格”分别展示方向及现盘对应星位，不选择尚未确定的前提，一般研究方向不等于最终喜忌。调候的指定日主月令原文尚未核对；当前提供另行标注的工程月支寒暖估计。
- 大运流年：固定 `lunar-python 1.4.8`，`getYun(..., sect=2)`。年干阴阳和用户提供的传统男／女参数决定顺逆；出生到前／后节的分钟差折算起运。十年区间以起运时刻周年递推，不拿库的公历年标签当精确切换日。

顺逆运参数只是本项目选择的传统计算体系，可留空；不从姓名、语气或身份猜测。精确出生时间与此参数缺失时不倒推起运。年龄字段为库的年段标签，不等于精确周岁。当前运以参考日12:00与起运区间比较，起运当天12:00之前或之后可能不属于相同区间。流年干支按该参考日的节气年，不把元旦直接当立春。出生早于支持范围、海外时区和真太阳时当前不支持。

## 每日运势与回顾

网页“每日运势与回顾”先保存档案，再生成日报。出生资料可留空，只用塔罗；有出生资料或四柱时加入八字，当日参考固定为中国标准时间12:00。结合八字时档案时区必须为 `Asia/Shanghai`；纯塔罗可用其他 IANA 时区。

```bash
fortune-report save --profile demo --birth 2000-01-01T12:00:00+08:00 --gender female
fortune-report report --profile demo --date 2026-10-05
fortune-report report --profile demo --date 2026-10-05 --interpret
fortune-report history --profile demo
fortune-report review --profile demo --key <日报key> --note '完成了论文小节，明天继续修改。'
fortune-report export --profile demo
fortune-report delete --profile demo
```

日报包括固定塔罗及原文、当日八字关系、逐本命柱与当日的合冲关系观察、大运流年依据、现代反思问题和可执行小步骤。塔罗与八字保持各自方法，不合成为客观好运分数。离线反思措辞是项目练习，不冒充古籍译义。

首次生成可选择模型解读。相同档案资料、日期与规则版本沿用首次报告；**首次离线保存后，同版本再次勾选模型仍沿用该离线报告**，不会偷偷产生第二份当天解读。出生资料或规则版本变化会生成新版本，同日塔罗不变；历史保留原快照供比较。历史页面展示最近366条，导出包含此代号全部日报及回顾。下一天按当地日期重新确定牌面，可能抽到相同牌。

统一对话：页面代号对应已保存档案、预览并确认复用后，“今天运势”使用档案生成综合日报；未确认档案则沿用每日塔罗。每日时区须与保存档案一致。追问复用同日报、牌面与八字依据，追问文字不覆盖归档首份日报。八字对话若出生时刻与已保存档案一致，可复用档案的顺逆运参数。

## 保存与模型请求

档案和综合日报保存在 `work/fortune.sqlite3`，文件权限600，数据明文保存于本机；回顾也保存在本机，不发送给模型。手动八字单次查询仍不保存出生资料。模型日报会发送相关出生资料、计算结果和参考原文；代号本身不进入解读输入。统一对话仍会发送用户消息和近期上下文。

删除仅清除此代号的综合档案、日报和回顾；独立“每日一张”使用旧的 `work/daily.sqlite3`，不会随综合档案删除。SQLite启用安全删除，但本机备份、中转站记录和已导出的文件不受该操作控制。导出文件包含出生资料，分享前应自行删除私人信息。

模型失败或空回答时不写入日报，可重试；已存日报不需要API配置。删除与正在生成的请求冲突时，不允许迟到的响应重新写回已删档案。

## 验证与尚缺内容

测试覆盖顺逆运和固定起运结果、精确周年边界、缺出生时间不计算、档案变化的缓存隔离、日报复现、回顾归属、导出、删除、空回答不保存、已存报告无需模型配置以及统一对话综合日报追问。历法结果基于选定库体系，未独立验证预测效力。

尚缺的是核心判命方法的完整资料与效力规则：人元司令、根气轻重、制化、从化、格局成败及完整调候。当前系统还提供公开参数的近似判断模型及条件规则，**不能把工程近似判断写成所有经典效力已经统一裁定**。

本批离线流程及真实模型有限验证见 [评估记录](../evals/results/complete-fortune-review-2026-10-05.md)。

本批判断层的参数、适用范围和字段说明见 [八字判断模型](bazi-judgment.md)。
