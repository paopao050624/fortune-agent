# 紫微解释依据

本批将《紫微斗数全书》卷一的27条实际摘录接入解释：十四主星、文昌文曲/左右/禄存/天马六个辅曜、禄权科忌四化，以及三个综合判断原则。来源为Wikisource固定电子修订7913704（修订时间2026-08-07），实际获取于2026-10-06。

## 来源与校核层级

[卷一固定修订](https://zh.wikisource.org/w/index.php?title=紫微斗數全書/卷一&oldid=7913704)。正文经Wikimedia官方页面接口取得，保留HTML哈希与各完整章节纯文本哈希；每条引用检查为该章节中的连续原文，不凭记忆补写。

数据保存于 `data/ziwei_sources.json`，包括ID、实际文字、章节、固定修订链接、校勘限制与现代反思。电子页混有简繁字，部分字词与别版可能不同，例如文曲条目“文车”等按实际转录保留，不静默改为其他字。没有确认纸本底本和纸本页码，不能说本批完成了纸本看图校勘或全书转录。

历史文本不等于现代性格/疾病/寿命/财富事实。对应完整章节包含旧时代性别偏见及宿命断语，程序与提示词明确禁止用来诊断、贬损或预言用户的现实事件。截取的概念句仍须连同章节上下文看待，不作为完整格局算法。

## 命盘匹配与展示

排盘仍由iztro 2.6.1固定算法完成。资料检索按实际星名、生年四化和宫位匹配，返回 `matched_positions`；不存在的辅曜或四化不伪造位置。三个综合方法段共用。`explanation_context` 列出实际命宫、身宫及命宫索引偏移0/4/6/8对应的对宫三方，资料选择规则可复核。

网页“按宫位查看原文依据”可筛选十二宫，显示对应星曜或四化的原句、章节、固定修订链接和现代反思问题。完整原文区保留全部实际匹配条目。命宫无主星时提示结合对宫与三方，不解释成缺少某个人生领域。

离线解读从实际命宫主星关联到对应摘录。中转站解读使用结构化JSON：summary、explanations、advice和limitations；每项explanations必须引用实际给出的唯一source_id，未知ID或无效结构被拒绝。原文和链接由程序插入，模型只生成传统概念解释与现代应用，不负责重写原文。中文“现代反思”是项目或模型的应用建议，不冒充书中结论。
