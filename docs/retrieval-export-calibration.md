# v0.3之后：检索、报告导出、评估与校准

v0.3.0是已发布固定快照；本页功能是该发行之后的主分支改进，未反向覆盖v0.3.0附件。

## 本地资料检索

“资料库检索”入口提供八字、紫微、塔罗、周易或全部类别搜索，当前665条来源条目。每项保留原文、定位、固定来源、版本限制及匹配原因。关键词排序可复核；这是本地词项检索，不声称语义搜索或回答正确率。

提问《穷通宝鉴》等尚未接入的典籍时，明确提示原文缺失，不用其他书冒充。单字卦名可查。模型解释八字/紫微时按实际资料和问题缩小上下文：日主、月令及方法必需锚点保留，紫微命宫主星与综合原则保留；引用仍校验ID。相关性排序不能替代原文适用条件。

## 报告导出

各结果提供“导出报告”，综合日报保留完整本次反思、行动与方法。支持HTML下载、浏览器打印/保存PDF、PNG图片。预览可选择包含出处、是否包含出生资料。星盘已有独立SVG导出，也可导出文字报告。

默认不显示明确的出生时刻、坐标与档案标识，已知敏感字段也在模型自由文字中替换。**这不是匿名化保证**：用户自行输入的名字、经历或地点仍可能出现在解读，请在分享前检查预览。开启包含出生资料是显式操作；档案JSON完整备份是另一个按钮，与公开报告分开。

HTML只通过转义后的文本生成，无脚本；PNG由本机SVG转为canvas，不调用模型或外部图片服务。超长图片报告会提示关闭出处或改用HTML/PDF。PDF调用浏览器系统打印，用户选择“保存为PDF”；不同浏览器打印对话框表现可能不同。

## 八字参数校准

`evals/bazi_calibration_cases.json`提供六个明确标记的合成结构锚点：训练两例、留出两例，以及参数敏感/特殊格防护两例。`scripts/calibrate_bazi.py`对四组阈值做可复现对照，并记录资料与规则哈希。

```bash
PYTHONPATH=src python scripts/calibrate_bazi.py
```

保留原0.42/0.58基准，没有用自造命理真值追求漂亮准确率。主要校准变更为：已测试情景产生不同旺衰分类时，`decision_status=abstain_final`，扶抑候选暂停选定，显示多方案；特殊从化方向同样保留复核。数值仍是工程模型生助占比，不是好运评分或古籍权威结论。

**独立专家标注数为0**。本批完成的是结构与稳健性校准，不是经典命理准确率验证；真正专家/有出处完整判例的校准仍需获得独立标签和确定流派，不能把同一程序生成的答案当校准真值。结果见 `evals/results/bazi-calibration-2026-10-06.json`。

## 扩大Agent评估

`evals/agent_expanded_cases.json`含20组真实提供方案例，覆盖六种工具、不同出生资料缺失、未知时辰/不全四柱、时区限制、确认档案、未确认资料保护、工具切换、稳定追问与周易策略切换。每例记录预期、实际结果和机制检查；服务异常与不匹配都计入失败，保留原始输出。

```bash
PYTHONPATH=src python scripts/evaluate_agent_experience.py --cases evals/agent_expanded_cases.json --output work/expanded-evaluation.jsonl
```

真实请求会产生费用。行为检查不验证占卜有效性或所有自由文本正确；独立复核与更广用户输入仍需补充。扩展结果与失败修正见 [本批评估](../evals/results/retrieval-export-calibration-review-2026-10-06.md)。
