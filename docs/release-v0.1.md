# v0.1 本地发布准备

此版本提供可运行的本地网页和命令行，覆盖塔罗、每日塔罗和有限八字分析。完整产品目标仍在推进，不包含紫微、易经、西方占星或完整用神、大运分析。

## 首次安装与体验

在项目根目录建立独立环境：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[agent,bazi]'
fortune-web
```

打开 `http://127.0.0.1:8765`。无需模型配置即可抽牌、看每日牌和八字排盘。首次测试可用虚构时刻 `2000-01-01 12:00:00`，检查四柱、十神、藏干与资料是否显示。

要开启模型解读，先停止服务，再配置中转站并重启：

```bash
cp .env.example .env
# 在本机编辑 .env 的密钥、地址和模型名
source .env
fortune-web
```

配置只影响从当前终端启动的进程。应用不会自动读取 `.env`；该文件已被 Git 忽略。勾选解读后资料会发送到中转站；每日解读保存到本机，其他问题与出生资料不保存。

## 演示步骤

1. 塔罗问答：输入“这周如何安排论文和复习？”，选择三张牌，查看牌位和来源。
2. 每日一张：使用固定代号和 `Asia/Shanghai`，重复查看，牌面应一致。
3. 八字：用虚构时刻排盘，展开十神、藏干与财格方法清单，检查未知条件仍明确显示。
4. 开启模型：只使用自己允许发送的资料；检查回答与牌面或四柱一致、引用来自已提供的资料。
