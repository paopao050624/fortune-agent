## 已核对的独立本

文件标识：`NLC416-11jh010455-35296`。来源记录为国家图书馆民国图书，Wikimedia Commons 提供扫描副本。

- 书名页题“秘本子平真詮”，署“沈孝瞻先生撰”，出版者为“上海世界圖書館發行”。这些字样已在 PDF 第 1 个扫描页看图核对。
- Commons 的馆藏元数据列出版时间为 `[19--?]`，没有确切年份。不能称作 1926 年本，也不能据此判为初刻本。
- PDF 共 287 个扫描页；馆藏描述的“126 页”不能直接作为 PDF 页号。
- 《论用神》起于 PDF 第 26 个扫描页，书内页码“十七”；正文延续到第 27、28 个扫描页，分别为书内“十八”“十九”。第 28 个扫描页随后进入《论用神成败救应》。这三页已完整看图核对。
- 文件 SHA-256：`71402a780b0351b54edf121a51bc4a4a4ce5896496c35b954563ee06f1a6f620`。

可核对的短句为：“八字用神。專求月令。”本句位于 PDF 第 26 个扫描页、《论用神》开篇。这里保留繁体，句读按扫描版的圈点转写；若作现代展示，可注明重新标点。

后文要求“逐干逐支參配而權衡之”，并讨论月令无用神的情况。因此，这段文字可以支持“从月令出发，再结合四柱”的历史方法说明，不能单独推出某命盘的确定用神，也不能直接化成“缺什么五行就补什么”的算法。

有一处需要校勘：扫描页 26 开篇印作“以干日配月令地支”，并非通行电子文本中常见的“以日干”。当前记录保留所见，不静默倒换；正式摘录时应标注原版字序，或引用不涉及该疑点的短句。整书尚未逐字转录，也未与其他版本完整校勘。

可先以世界图书馆独立本作为“已看图核对的工作底本”，分章人工转录，保存扫描页号、书内页码、文件哈希和疑字。先处理《论用神》《论用神成败救应》《论用神变化》，核对规则的适用条件后再进入模型证据。初期可引用已核对的短段，不能声称整本已整理或各版本完全一致。

查找阶段没有修改 Agent 的用神判断行为；后续接入的四个短段只提供来源说明，完整的格局和用神计算仍需要逐条建立规则并验证。
