# 八字判断模型 v1

八字页、完整报告、统一对话与综合日报现在共同使用 `bazi-estimate-v1`：给出旺衰分类、格局配合与风险条件、救应观察、扶抑候选五行、调候方向及特殊格筛选。它是项目近似模型，权重与条件代理公开，不是古籍提供的数值算法，也尚未经过专家校准或预测效力验证。

## 旺衰估计

显干按权重1计，日干作为参照不重复计入。四支藏干按显式天干键对应权重分配；月支权重1.8，其他支1。季节倍率体现模型对旺相休囚死关系的近似表达，辰未戌丑保持倍率1，不统一把土判旺。不能把权重叫作人元司令天数。

同类及生我元素的权重占比为生助比例。小于0.42估计偏弱，大于0.58估计偏强，中间估计相对均衡。它不是好运分、现实概率或古籍标准。

| 参数 | 工程约定 |
| --- | --- |
| 显干 | 1，排除日干本身 |
| 月支 | 1.8 |
| 其他支 | 1 |
| 一藏干支 | 1 |
| 二藏干支 | 0.7 / 0.3；午丁己、亥壬甲 |
| 三藏干支 | 主次权重0.6 / 0.3 / 0.1，按明确天干键配置，不依事实表列表顺序 |
| 巳 | 丙0.6、戊0.3、庚0.1，与藏干事实表展示顺序分开 |
| 稳健性情景 | 月支权重1.3 / 1.8 / 2.3，受冲支权重保留0.7 / 1 |

六种情景分类一致时标“参数稳定”，不一致标“参数敏感”。这只检验模型对这些参数的变化，不是判断正确性的置信度；不宣称冲必然削弱30%，也不将冲后根气自动删除。完整倍率、贡献行、情景与阈值在网页和JSON中可查看，参数数据进入参考库哈希。

## 格局与成败条件

普通月令候选按月藏干同干透出优先，再按明确藏干模型权重排序；多候选全部保留。建禄、月劫、阳刃采用既有月支映射，另查配合。杂气会支与合冲争合仍展示，不从数值排序强行宣称唯一经典格局。

程序对正官、正偏财、正偏印、食神、七杀、伤官及禄劫刃路径执行条件规则，返回：

- `supported_conditions`：所列模型配合条件满足。
- `mixed_conditions`：配合与待审条件同时出现。
- `risk_conditions`：所列模型风险条件出现。
- `conditions_not_met`：所列配合条件没有满足。

这些状态不是命局吉凶或经典最终成败。15%的星权重比例作为“旺／轻”的条件代理、星同现作为“逢”的代理、月支关系名称作为刑冲核查代理，都属于项目约定。存在某星不证明实际相生相制有效；财印位置、司令、根力和救应实际效力不能由这几个代理穷尽。

成格、败因和救应相关原文新增10个扫描核对摘录：PDF扫描28–30页、书内19–21页。救应条目包含非连续片段，省略处以“……”明确标示；羊刃原字保留。当前《子平真诠》共21个短段，不代表整本转录。

## 分方法取用

扶抑：模型偏强列出泄、耗、制元素候选；偏弱列出生、扶候选；相对均衡不强行选喜用。它们是需要结合格局择用的候选，不把多项同时定喜，也不根据五行缺失决定补充。

调候：亥子丑列温暖方向，巳午未列润泽方向，戌列燥土润泽方向，其余月无通用优先项。**这是项目按月支设计的通用方向，不是《穷通宝鉴》逐日主逐月的完整取用算法。**原文在线来源本批访问失败，没有把未取得的文字加入参考库。所有日主的结果都带该说明。

两种方法候选与避免增加的元素重叠时，列出冲突，不压成一个最终用神。格局用神的历史含义和扶抑喜用分开。

## 特殊格

极低／极高生助比例给出从弱／专旺方向筛选；检查日主根气、印生助等代理。日干五合检查相邻、同类根与化神元素占比；满足条件只给特殊研究候选，不自动判化气格成立。触发特殊方向时暂停常规格的具体扶抑喜用，避免套用相反方法。

没有明确出生时间或顺逆运参数仍不能计算起运；原有法定时间排盘、用户四柱验证限制保留。真太阳时、海外时间体系和各派司令版本并未在本模型中统一实现。

## 验证

测试覆盖十个日主与六十个月柱的组合、明显不同的生助结构、权重守恒、日干不重复计、月令参数变化、冲支情景、候选来源、特殊筛选和取用方法分离。所有模型数值、条件及来源可复核，但工程测试通过不等于命理断言或现实预测成立。
