# 八字古籍资料

资料包含 Wikisource《滴天髓辑要》的十干原文及两个方法短段，以及已看图核对的《子平真诠》七个短段。每段保存名称、原字、章节定位和必要的转录疑点。《子平真诠》另有书内页码与扫描页号，详见 [扫描摘录](ziping-transcription.md)。这些资料不能自动推出整盘格局、用神或大运。

来源为 [滴天髓/02 固定修订 11117658](https://zh.wikisource.org/w/index.php?title=滴天髓/02&oldid=11117658)。这是一份电子转录，尚未与扫描底本或指定纸本校勘；该批数据不确证作者归属和底本版本，也不提供纸本页码。这里只提取历史原文，不收录页面中与原文交错的解释性段落。古籍原文使用开放的历史文本，Wikisource 的来源与定位保留在每条资料中；现代校注、翻译和图片需要另外确认授权。

方法短段取自 [月令论，修订 844366](https://zh.wikisource.org/w/index.php?title=滴天髓/17&oldid=844366) 和 [衰旺论，修订 844360](https://zh.wikisource.org/w/index.php?title=滴天髓/12&oldid=844360)。它们说明月令与旺衰在传统分析中的位置，不提供足够规则判断某张命盘的用神。页面注解提到的人元司令天数未进入这批资料，也不用于计算。

转录的丁火段作“抱乙而考”，戊土段作“火燥囍潤”。资料保留这两个写法并标注尚未校勘，不静默改为其他版本的文字。模型引用应忠实保留原字，或只引用无疑点的短句，同时说明资料仍有转录问题。

## 使用

无需 API 即可查看日主相关资料：

```bash
fortune-bazi --birth 2000-01-01T12:00:00+08:00 --sources
```

带 `--interpret` 的问题会把四柱与对应原文一起发送到中转站。JSON 输出包含 `evidence`；文本输出会在解读之后显示程序保存的原文和固定来源，不依赖模型是否生成链接。

为使引用可检查，模型应分别说明原文、传统语义解释和现代行动建议。原文对水火、寒暖等关系的描述不能直接当作用户的人格、能力或健康事实。仅凭日主取一段原文，也不能推断命局全貌。

## 重建资料

在项目根目录运行：

```bash
python scripts/fetch_bazi_sources.py
python scripts/build_bazi_sources.py
python scripts/build_bazi_context_sources.py
```

抓取使用固定修订号，原始转录保存在 Git 忽略的 `work/`。构建脚本检查十干是否齐全、唯一，提取后的 JSON 会随 Python 包发布。若要改用其他版本，请先核对文字与定位，并更新版本说明；评估续跑会检查资料哈希，阻止与旧资料结果混用。

《渊海子平》《三命通会》《穷通宝鉴》仍未接入。《子平真诠》仅接入上述七个短段，版本信息和疑点见 [查找记录](ziping-editions.md)。《渊海子平》Wikisource 页面标注未注明来源，底本不能确认，因此没有把它作为模型证据。下一批资料需逐条核对适用条件，再决定如何用于解释。
