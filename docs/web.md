# 本地网页体验

安装Python可选依赖 `.[all]` 和Node.js 18+，在项目目录运行 `fortune-web --port 8766`，访问 `http://127.0.0.1:8766/`。不指定端口时默认8765。默认仅绑定本机回环地址；Docker内部可显式设置 `--bind 0.0.0.0`，Compose仍只向本机发布，尚无公网账户认证。

页面有八个入口：统一对话、塔罗问答、每日一张、每日运势与回顾、八字排盘、紫微斗数、西方占星和周易起卦。切换工具不会自动清除已有对话；“新对话 / 清除”只删除当前内存会话。

## 工具流程

- 塔罗先写问题，再服务端洗牌、选择78张背牌的位置、翻牌。支持单张、普通三张、选择对比、五张行动和凯尔特十字。重复揭示不改牌面；改选需重新洗牌，追问使用原牌面。
- 每日一张按代号和当地时区固定牌面，首次模型解读缓存。综合每日运势是另一个入口，使用保存档案加入八字参考、大运流年依据与历史回顾。
- 八字可按准确中国标准时间排盘或直接输入四柱。展示十神藏干、结构关系、项目旺衰估计、格局条件、喜用候选及具备资料时的大运。直接四柱只检查单柱合法性，不假填出生时间。
- 紫微显示固定iztro本命十二宫与星曜四化；占星显示热带整宫制的十大天体、角点及相位。选择“使用档案”时禁用未使用的手填字段，结果注明实际出生时间。
- 周易录入六次和数或模拟投掷，显示主变卦与动爻；可切换取辞策略、查阅64卦全文及请求结构化解读。

## 保存与模型调用

模型密钥从启动终端环境读取，不发送回浏览器。手动计算默认不调用模型；统一对话及显式勾选解读会调用中转站。单次查询不默认保存出生资料，但主动保存档案或工具历史会写入 `work/fortune.sqlite3`；综合日报、回顾、导出与恢复也使用此库。独立每日塔罗使用 `work/daily.sqlite3`。本地回顾不进入模型请求，详见 [档案说明](charts-and-profiles.md#档案)。

模型回答支持加粗、标题、列表、引用、代码和简单表格，使用安全的DOM节点排版；模型提供的HTML不执行，链接只允许HTTP/HTTPS。结果默认先展示概览、解读和行动建议，命盘、计算参数与原文按需展开；聊天依据区不重复整段回答。输入由后端校验，请求必须带页面临时token与允许的本机Host。容器映射到不同宿主机端口时，使用 `--external-port` 明确增加允许端口，不开放任意域名。

## 验证

真实Chrome桌面与手机验收覆盖五种牌阵、每日稳定性、八字、周易、档案导入导出与删除、回顾、两种星盘及聊天界面；完整HTTP测试和Docker重启持久化验证已经通过，并已加入CI。模型相关浏览器响应使用明确测试替身；本批未调用真实中转站。可复现脚本和结果见 [验证报告](../evals/results/web-docker-review-2026-10-06.md) 与 [贡献指南](../CONTRIBUTING.md)。
