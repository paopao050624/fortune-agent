# 本地网页体验

在项目根目录安装 `.[agent,bazi]` 后运行 `fortune-web`，浏览器访问 `http://127.0.0.1:8765`。源码运行可用 `PYTHONPATH=src python -m fortune_agent.web`。服务仅绑定 `127.0.0.1`，不作为公开网站部署。

页面提供三项功能：塔罗问答支持单张、三张及选牌位置；每日一张按代号与时区固定当日牌面；八字使用精确的中国标准时间排盘，展示十神、藏干、原文和未核实的财格条件。原文与结构化结果均可展开查看。

“周易起卦”页录入六次和数或模拟投掷，显示主变卦、爻图和投掷记录；可以选择取辞策略、查阅全部 64 卦经文或请求结构化模型解读。实际引用由程序提供，模型条目 ID 必须经过校验。详见 [起卦约定](iching.md) 和 [解读规则](iching-interpretation.md)。

八字页可选择“按出生时间排盘”或“直接提供四柱”。直接输入时显示用户提供和出生时间未核对的提示，未知时间不补成假定日期。服务会拒绝同时提供出生时间与四柱，以及不合法的单柱干支；只有输入合法后才可能调用模型。

默认只进行本机计算。勾选“生成模型解读”才调用已配置的中转站；模型密钥与接口配置从启动终端环境读取，不由网页输入或发送回浏览器。出生时间及问题可能被发往中转站，但服务不会在本机保存它们或记录请求正文；每日首次解读仍保存到指定缓存文件。

每日缓存命中时无需中转站配置，返回当天首次回答和风格。服务对每日首次解读加锁，避免同一进程同时收到多次请求时重复生成；这不构成跨进程的计费锁或多人账户系统。

模型回答作为文字显示，页面不把它当作 HTML 执行。请求需要本地页面提供的临时令牌和本机 Host，输入在服务端再次校验。更改端口用 `--port`，指定每日数据库用 `--cache`。停止服务按 `Ctrl+C`。

本轮验证了三个 HTTP 功能、输入错误、请求令牌、本机 Host、中转站错误信息隐藏和每日缓存复用；全项目 61 项测试通过。页面脚本语法与发布包资源已检查。自动浏览器启动受到运行环境限制，尚未完成截图或真实浏览器布局验收；本轮没有新增真实模型请求。现有三个解读模块仍复用此前的中转站实现。
