# 资料与方法

以下是各模块的参考资料。塔罗已接入 Waite 原书转录释义，八字已有四柱、十神与藏干计算，以及《滴天髓辑要》的十干和方法摘录。接入每个方法前，需要记录具体版本、规则出处、计算步骤和可验证样例。

| 模块 | 已接入依据与候选书目 | 当前方法与边界 |
| --- | --- | --- |
| 紫微斗数 | iztro 2.6.1排盘；《紫微斗数全书》（传统参考，全文未校勘） | 固定本命十二宫、星曜及四化算法，明确农历年界、闰月和晚子时规则；不编造古籍引文。见 [星盘指南](charts-and-profiles.md)。 |
| 八字 | 《滴天髓辑要》十干及方法短段；《子平真诠》二十一个扫描核对短段；《渊海子平》《三命通会》《穷通宝鉴》（候选，未接入）；`lunar-python 1.4.8`（排盘） | 已计算月令、根气、透干与研究候选；项目模型已计算旺衰、格局条件与取用候选；古籍最终效力与各派差异另作复核，详见 [规则体系](bazi-rule-system.md)。 |
| 易经 | 《周易》固定修订卦序、64 卦辞、384 爻辞及用九用六 | 三枚硬币起卦、明确项目取辞规则与结构化解读；电子转录未作全书底本校勘，见 [解读规则](iching-interpretation.md)。 |
| 塔罗 | A. E. Waite, *The Pictorial Key to the Tarot*, Part III（已接入文字释义） | 78/78 张牌均有原书页码；原书未为圣杯二提供逆位释义。牌图的授权需单独核对。 |
| 西方占星 | Astronomy Engine 2.1.19；托勒密《四书》/ *Tetrabiblos*（书目候选，未接入原文） | 十大天体、热带黄道、地心位置、整宫制与明确IANA时区经纬度；非所有宫制或合盘。见 [星盘指南](charts-and-profiles.md)。 |

塔罗文字取自 [Wikisource 的原书第三部分](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot/Part_3)，每张已录入的牌保留具体扫描页链接。原书措辞有时代局限，也常包含宿命式表达；它是历史参考资料，不构成对用户现实处境的证明。模型不能把未核对资料说成书中原文。未来若提供其他书籍依据，应把可核对的原文或整理后的规则放入知识库，并标明书名、版本和定位信息。古籍原文与现代译注、校注及塔罗牌图的版权状态要分别确认。

可在项目根目录用 `python scripts/fetch_waite.py` 下载所需文字页，再用 `python scripts/build_waite.py` 重建 `waite_meanings.json`。抓取脚本需要 `curl` 和网络访问；原始转录暂存于 Git 忽略的 `work/`。转换脚本在缺页、重复牌或总数不是 78 时会失败。

八字原文的版本、转录疑点与重建方法见 [八字古籍资料](bazi-sources.md)。

《子平真诠》独立本已有二十一个扫描核对短段接入，详见 [扫描摘录](ziping-transcription.md)、[财格方法清单](bazi-wealth-checklist.md) 和 [版本查找记录](ziping-editions.md)。
