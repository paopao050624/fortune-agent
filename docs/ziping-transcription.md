# 子平真诠首批扫描核对摘录

资料使用国家图书馆来源的世界图书馆《秘本子平真詮》扫描副本，包括《论用神》四个短段及《论用神成败救应》财格成格条件一句。程序在八字解读时提供这些方法性资料；不声称整章或整本已转录，也不自动取格或判定用神。

第一批结构分析另加入“论十干得时不旺失时不弱”的月令与有根两段（书内第 13 页，PDF 第 22 个扫描页）。这两段是方法依据，整章尚未转录、根气轻重规则尚未全部实现。当前共七个扫描核对短段，结构说明见 [规则体系](bazi-rule-system.md)。

| 条目 | 书内页码 | PDF 扫描页 | 范围与提示 |
| --- | --- | --- | --- |
| 月令起点 | 17 | 26 | 保留“以干日”字序，未按通行文本更正 |
| 四柱配合 | 17 | 26 | 说明逐干逐支配合权衡，完整顺逆条件尚未做成规则 |
| 月令无用神的设问 | 18 | 27 | 必须说明它是有后续例子的设问，不能单独当取用算法 |
| 设问后的补充说明 | 19 | 28 | 承接上页的条件讨论，不能据此直接断定财格 |
| 财格成格条件 | 19 | 28 | 本章三条财格成格路径，条件清单分别保留尚未核实的信息 |
| 月令非最终旺衰 | 13 | 22 | 月令之外仍须考虑四柱损益 |
| 有根的方法观察 | 13 | 22 | 有根文字不等于程序已判根力或最终旺衰 |

原字保留，标点按现代句读整理并在数据中注明。世界图书馆版出版年份未定，不能把它称作已确认的 1926 年本。摘录看图核对的是指定扫描本，不代表版本间的字词完全一致。

`src/fortune_agent/data/ziping_sources.json` 保存工作底本标识、文件 SHA-256、原文、双重页码、来源链接和疑字。模型只允许引用已提供的短段，对《滴天髓》等尚无纸本页码的电子转录仍不能编造页码。命令行可离线查看：

```bash
fortune-bazi --birth 2000-01-01T12:00:00+08:00 --sources
```

扫描文件保存在 Git 忽略目录。可用下列命令下载并核对同一工作底本；若远端文件变化，哈希校验会失败，不会静默替换原底本：

```bash
python scripts/verify_ziping_scan.py --fetch
```

继续转录时，应先打开完整相关页，再记录短段的上下文、扫描页和书内页。疑字要显式说明；新段进入模型前，应核对适用条件并增加引用与过度推断的评估案例。现已有限整理《论用神成败救应》的财格成格句，见 [财格方法清单](bazi-wealth-checklist.md)；本章其他内容和《论用神变化》仍待整理。

原始版本查找过程和合刊候选见 [版本记录](ziping-editions.md)。
