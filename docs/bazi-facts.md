# 四柱的十神与藏干关系

`--details` 输出由程序计算的每柱天干五行、阴阳、相对日主的十神，以及地支藏干和各藏干的十神。月令在这一步只定位到节气月对应的月支，不计算人元司令分日。

十神是传统关系名称。程序按十天干在“木、火、土、金、水”循环中的位置和阴阳计算关系：

| 目标天干与日主关系 | 阴阳相同 | 阴阳不同 |
| --- | --- | --- |
| 同五行 | 比肩 | 劫财 |
| 日主生目标 | 食神 | 伤官 |
| 日主克目标 | 偏财 | 正财 |
| 目标克日主 | 七杀 | 正官 |
| 目标生日主 | 偏印 | 正印 |

地支藏干表与 `lunar-python 1.4.8` 对齐。测试逐一核对全部 100 种天干关系与 12 地支藏干列表。这验证项目与选定计算规则一致，不是对命理现实预测效力的验证。

例如 `2000-01-01T12:00:00+08:00` 排盘的日主是戊，月柱是丙子：丙为阳火，相对戊是偏印；月支子藏癸，癸为阴水，相对戊是正财。这些关系只描述传统分类，不能据此断定财格、财富或个人能力。

```bash
fortune-bazi --birth 2000-01-01T12:00:00+08:00 --details --sources
```

藏干列表的顺序不充当权重，程序没有把“第一个藏干”解释为“最旺”。这个基础关系模块不判格局、旺衰或取用。完整报告另有 [项目判断模型](bazi-judgment.md) 和 [起运大运](complete-fortune.md)：工程权重按天干键显式配置，不依本模块藏干列表顺序，模型估计与经典最终效力分开。
