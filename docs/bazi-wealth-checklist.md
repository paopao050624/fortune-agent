# 财格方法条件清单

本功能整理《子平真诠·论用神成败救应》的财格成格句，为命理学习提供“已观察的信息”和“尚未核实的条件”。当前不能确定某命盘属于财格，也不能输出已经成格或确定用神。

工作底本仍为世界图书馆扫描本：书内第十九页，PDF 第 28 个扫描页。人工看图核对的句子为：“財旺生官，或財逢食生而身強帶比，或財格透印而位置妥適，兩不相剋，財格成也。”原字保留，标点按现代句读整理。来源见 [扫描页](https://upload.wikimedia.org/wikipedia/commons/f/fe/NLC416-11jh010455-35296_%E5%AD%90%E5%B9%B3%E7%9C%9F%E8%A9%AE.pdf#page=28)。

## 三条方法路径

| 路径 | 程序展示的相关观察 | 未核实的关键条件 |
| --- | --- | --- |
| 财旺生官 | 财星、正官是否在天干可见 | 财格归属、财旺、有效的生官配合 |
| 财逢食生而身强带比 | 财星、食神、比肩或劫财是否在天干可见 | 财格归属、有效食生配合、身强、原文带比条件 |
| 财格透印而位置妥适、两不相克 | 财星、正印或偏印是否在天干可见 | 财格归属、所见印星的适用条件、位置妥适、两不相克 |

这些观察不等于原文条件已经满足。例如“印星天干可见”只描述十神的位置，不等于位置妥适、两不相克或财格成立。正印、偏印作为观察合并展示，也没有自动判定该路径如何采用正偏印。

四柱的日干是判断基准，不能又把它计成一个额外透出的比肩。藏干不计入天干可见观察；“未见透干”不能说成命盘中完全没有该星。月支中的财星藏干会另行列出，也不能直接当作财格结果。

## 使用和验证

```bash
fortune-bazi --birth 2000-01-01T12:00:00+08:00 --analysis
```

不调用 API 即可查看清单。JSON 输出中字段为 `method_checklist`，解读时同一份程序结果发送给模型。所有路径标为 `unverified`，总体结论为 `undetermined`。

`bazi_wealth_rules.json` 保存路径与原文条目 ID；引用文字与页码位于 `ziping_sources.json`。评估续跑核对规则数据哈希及实际清单，阻止变更规则后与旧结果混用。

加载规则时还会核对三条唯一的路径、原文对应短句、章节与双重页码、观察字段，以及必须保留的待核实条件。删掉“身强”“位置妥适”或“两不相克”等条件，或者把扫描页与书内页混用，都会使加载失败。若主动更换底本或条件解释，需要同时修改校验依据、记录差异并重新测试；这项核对保证资料链一致，不能替代人工校勘。

目前仅整理了本章财格成格这一句，败格、救应、其他格局和旺衰规则均未实现。测试检查透干与藏干区分、日干排除和未核实条件的保留；这不是命理预测有效性的验证。
