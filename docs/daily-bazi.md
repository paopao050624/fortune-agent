# 每日八字参考

这一功能将本命日主与指定日期的干支作传统关系比较。它没有大运、旺衰、合冲刑害权重或喜用神计算，因此不提供吉凶分数、升职进账保证或疾病判断。

程序采用中国标准时间该日 **12:00** 作为固定历法参考，得到年柱、月柱和当日干支，逐项计算相对本命日主的十神与藏干关系。选择固定参考时刻的目的是使同一天的计算可复核；不是假定用户在中午出生，也不输出当日时柱。

年与月仍按节气划分。若当天发生节气切换，12:00 前后的某些时段可能与参考月柱不同。结果提供前后“节”的时刻和该限制。日干支按现有 `sect 2` 规则，当地午夜换日，23:00 不提前换日。此版本的每日八字参考只按中国标准时间确定日期，不使用网页的每日塔罗时区。

## 使用

```bash
# 今日干支关系，只做本地计算
fortune-bazi --pillars '己卯 丙子 戊午 戊午' --daily

# 指定参考日期，便于复现
fortune-bazi --pillars '己卯 丙子 戊午 戊午' --daily --date 2026-10-04 --json

# 使用已配置的中转站解释
fortune-bazi --pillars '己卯 丙子 戊午 戊午' --daily --interpret '今天怎样安排学习？'
```

本命资料也可以来自 `--birth` 公历出生时刻。用户直接提供的四柱依旧只作单柱合法性检查，未知的本命时间规则不会因为今日历法计算而变成已验证。

网页八字页可勾选“加入每日八字参考”。统一对话可说“用八字看今天的学习安排”，助手先询问本命资料；普通“今日运势”未确认复用档案时使用每日塔罗，预览并确认档案后使用明确标注塔罗与八字各自依据的综合日报。每日八字追问复用本命资料，跨过中国标准时间午夜时重新计算当日参考。

## 解读边界与保存方式

模型接收 `chart`（本命）与 `daily_context`（当日）两个独立字段，不能混淆。原文资料仍来自已收录的《滴天髓》和《子平真诠》有限摘录，它们不是某天会发生事件的证明。

伤官、偏财、正官等是传统分类名称，不等于今日失败、获得收入或升职。模型只可把关系作为反思角度，结合实际任务提出可选择的行动建议；建议是现代类比，不声称出自某段古籍。敏感决定仍须依据实际信息和专业判断。

出生资料与每日八字解释不写入本地数据库。对话暂存遵循统一对话的内存规则，手动八字页面每次解释可能产生不同措辞；同一天程序计算的干支关系固定。它与每日塔罗保存首次解读的机制不同，页面已分别说明。中转站请求仍会发送本命资料、当日关系和问题。

测试覆盖固定日期复现、本命与当日柱分离、午夜跨日、立春参考边界、十神关系、模型输入与网页的离线操作。历法结果与固定库规则一致，不表示已通过另一独立天文算法校验。
