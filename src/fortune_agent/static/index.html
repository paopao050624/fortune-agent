  • 使用 78 张塔罗牌，每次重新洗牌，同一次抽牌不会重复；正位、逆位各有一半机会。

  • 解读结合你的问题、牌位与正逆位，原文依据可查看；不会保证未来结果。

规则简介 · 每日一张

  • 只使用一张塔罗牌，暂不结合八字、生肖或星座。
  • 日期按你填写的时区计算。同一代号、时区和日期得到同一张牌，次日重新确定；不同日期也可能出现相同牌面。
  • 当天首次模型解读会保存到本机，重复查看沿用该回答与风格；固定代号用于区分每日结果，不需要真实姓名。

规则简介 · 八字排盘

  • 出生时间排盘仅支持中国标准时间；年、月按节气划分，23 点进入子时，日柱在 0 点换日，未做真太阳时校正。
  • 也可直接输入年、月、日、时四柱；只检查单柱干支是否合法，无法核对出生时间或排盘方法。
  • 展示日主、十神、藏干与古籍依据；财格清单会列出尚未核实的条件，完整报告展示旺衰证据、格局待核实项与分方法取用；提供出生时间和顺逆运参数可算起运、大运流年。判断层提供项目旺衰估计、格局条件与分方法喜用候选，参数公开；学派分歧、特殊从化与效力条件保留复核。可勾选每日八字参考，以今日12:00干支关系作反思依据。

规则简介 · 周易起卦

  • 每次投三枚硬币，正面计 3、反面计 2，六次和数按“初爻到上爻”填写；留空则模拟投掷。
  • 6、8 为阴爻，7、9 为阳爻；6、9 是动爻，翻转后形成变卦。输入从下到上，爻图从上到下显示。
